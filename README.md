# NIST-AI-RMF-Independent-Audit-Project
This repository is meant to conduct an independent audit on a data of my choosing and evaluate it against the criteria provided by the NIST Risk Management Framework

# MAP Function Analysis 
The dataset I chose to use for this project is the Customer Shopping Trends dataset from Kaggle. This dataset is meant to offer valuable insights into consumer behavior and purchasing patterns. This is crucial for businesses to tailor their products, marketing strategies, and customer experience in order to be attractive to multiple consumer segments. This dataset consists of the customer ID, age, gender, items purchased, category, purchase amount (USD), location, size, color, season, review rating, subscription status, shipping type, discount applied, promo code used, previous purchases, payment method, and frequency of purchases. 

My goal in this project is to run an independent audit of this dataset. Specifically, I hope to detect predatory marketing by testing whether an AI model targets vulnerable groups with higher prices. Predatory marketing is a major concern in domestic governance. If a machine learning model uses features such as age and gender to predict who gets a discount applied or a promo code used, it risks creating systemic inequalities, especially if it targets lower or working class consumers. Since there is no predefined category that explicitly indicates a consumers socioeconomic status, the model might use other proxies to indicate this, such as location (zip/address), payment method (cash/credit), and frequency of purchase. 

This model might also learn to withhold discount opportunities from a specific age group or gender based on historical data, which forces consumers from lower income brackets to pay higher average prices for identical goods or services. This model could be strongly biased against younger consumers (ages 16-24) because this is the age group that tends to have the most frequent purchases with the lowest income per capita. However, these impulse purchases are often impulsive. Nevertheless, this could potentially drive predatory financial behaviors. Aside from younger consumers, this model could also be biased towards women, who earn less income per capita than men, but also tend to be more frequent shoppers. This shows a pattern that the more vulnerable groups tend to be frequent shoppers with relatively less income. Therefore, according to my definition, the most vulnerable group that this model might target are young women. 

# Manage
As a result of the findings in the Measure phase - where the model found a disparate impact ratio violating the 80% threshold - the organization will pursue a strict risk mitigation strategy. The objective is to bring the selection rate variance within acceptable domestic regulatory boundaries without structurally crippling business profitability.
