# NIST-AI-RMF-Independent-Audit-Project
This repository is meant to conduct an independent audit on a data of my choosing and evaluate it against the criteria provided by the NIST Risk Management Framework

# MAP Function Analysis 
The dataset I chose to use for this project is the E-Commerce Sales & Profit Analysis dataset from Kaggle. The dataset contains 3500 e-commerce orders with 7 key features. It captures sales transactions across different products, categories, and regions, along with quantity, revenue, and profit details. This dataset will be important for transforming raw, transactional data into actionable insights, which can help sellers decide which products are popular in which categories and regions. This will help drive revenue growth as well as optimizing operations. This dataset can potentially help businesses understand customer behavior, identify profitable products/regions, refine marketing strategies, and make data-driven decisions to increase efficiency and profitability. 

However, this dataset has a few limitations. It primarily tracks e-commerce sales in the electronics industry. It's defined categories are office, accessories, and electronics, and it has distinct products in each category. Also, the region column is somewhat vague since it only classifies North, South, East, or West. Although this dataset seems to be more basic than expected, It should still be a good introductory dataset for getting insight into the process into conducting an independent audit. If this audit works, then I can be confident that I will be able to conduct more audits with more complex datasets in the future.
